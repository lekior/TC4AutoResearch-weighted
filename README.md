# TC4AutoResearch-weighted

面向 Minecraft 1.7.10 / Thaumcraft 4 的客户端研究辅助模组。它会在研究台中提供自动求解、要素合成、批量研究和研究搜索，并支持按库存调整的加权求解。

这是 [TC4AutoResearch](https://github.com/cdj68765/TC4AutoResearch) 的 Fork。当前版本移除了旧的 Windows C# 外部求解器，全部逻辑在模组内运行。

## 下载与安装

从 [Releases](https://github.com/lekiork9z-star/TC4AutoResearch-weighted/releases/latest) 下载正式 jar，将其放入**客户端**的 `mods` 目录后启动游戏。

- 适用于 Minecraft 1.7.10，并需要可用的 Thaumcraft 4 研究台。
- 本模组只在客户端运行，不需要在服务器安装；服务器仍须允许正常的 Thaumcraft 研究台操作。
- 不要安装 Release 中的 `-dev.jar`。

## 基本操作

打开研究台后，模组会在界面两侧加入功能按钮。

1. 放入未完成研究笔记，点击 **解锁当前笔记**。
2. 等待完成报告显示服务端确认；缺失的中间要素会按方案自动合成。
3. 若纸张、笔与墨或基础要素不足，补充资源后重新执行；**重试上次方案**可复用仍然有效的求解结果。

执行期间不要手动移动当前笔记、研究台笔墨或用于自动学习的快捷栏物品。批量研究和笔记生成还需要至少一个空背包格用于笔记的传输。

## 功能说明

### 求解与权重

- **常规最短**：优先选择步骤较少的连接方案。
- **加权最短**：点击 **研究要素权重** 设置要素权重、禁用要素、套用 Wiki 默认值，或按研究台当前库存分配权重。权重越高，越不会被选作中间要素。
- **自动解锁笔记**：开启后会监视新放入的笔记并自动开始求解；再次点击即可停止。
- 按住 `Ctrl` 点击研究台中的要素，可输入数量并从基础要素开始合成。

### 批量与一键研究

- **批量研究并解锁**：依次处理研究台与背包中已有的有效研究笔记。
- **搜索研究**：按中文名、研究 key 或目录筛选；可解锁笔记、所选笔记及其前置，或当前范围内全部可研究笔记。
- 已完成的发现会临时换入当前快捷栏并使用，随后恢复原物品。
- 在搜索研究中选择想要解锁的研究会一键消耗笔墨和纸张进行笔记解锁，且能显示所有需求前置进行查看。

### 传输恢复

所有笔记转移都等待服务端确认。服务端拒绝时，模组会先等待完整库存同步，再按 `1 / 2 / 4 / 8` Tick 退避重试；单次转移最多发送 4 次。每次重试都会核对源 `ItemStack` 与研究笔记状态，避免在服务端已执行操作时重复操作。

## 配置文件

- `config/TCAutoResearch.cfg`：自动解锁与求解器设置。
- `config/TCAutoResearch-weight-profiles.json`：保存的权重方案。

## 构建

需要 JDK 17 和已缓存的 Gradle 依赖：

```powershell
.\gradlew.bat build --offline --no-daemon
```

正式 jar 会生成在 `build/libs/`。提交前可运行：

```powershell
.\gradlew.bat spotlessApply test --offline --no-daemon
```
