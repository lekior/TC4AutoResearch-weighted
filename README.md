# TC4AutoResearch

## 研究搜索与前置队列

研究台右侧的“搜索研究”会打开可搜索的未研究项目列表。可以用目录图标选择当前目录，再按中文名、研究 key 或目录名筛选：

- “解锁所选”：只生成并求解所选研究；若服务端仍判定缺少前置则停止并提示。
- “解锁所选及其前置”：先显示可滚动的完整前置清单和每项实时执行方案，确认后按父项优先、目标最后的去重顺序逐张学习、求解或生成。
- “解锁范围内全部可研究”：按页面当前的“当前目录 / 全部目录”范围，生成、求解并学习服务端已经满足前置的研究；每完成一层会重新检索新满足前置的项目，直到没有新项目或资源不足。

搜索队列一次只处理一张笔记。完成的笔记会通过原版容器事务临时换到当前快捷栏并模拟右键；服务端确认研究完成后，原快捷栏物品会换回并继续下一项。学习研究仍会正常触发 Thaumcraft 的扭曲与其他原版副作用。每次容器事务接受后会等待五个 Tick 和目标槽位稳定；交换被拒绝时先等待服务端完整库存重同步并自动重试一次，第二次拒绝、物品持续变化或确认超时才停止。客户端不会强改研究状态。隐藏研究只有在游戏已经揭示后才进入流程；虚拟、占位、自动解锁和当前难度下不会产生笔记的研究会停止并给出原因。

生成笔记使用 Thaumcraft 原版 `PacketPlayerCompleteToServer` type 1。服务端负责复核前置并消耗纸张和玩家物品栏中的笔与墨；模组只在服务端确认对应笔记出现在物品栏后推进。满物品栏、缺纸、断墨、容器事务被拒绝或确认超时都会安全停止。研究台中的笔与墨可临时移入物品栏用于生成，转移和归还都等待原版容器事务确认。

前置字段语义参考灰机 Wiki 当前页面 `神秘时代研究表格`（修订 672423，2026-07-01）、`模块:神秘时代研究表格`（修订 198434，2026-05-06）和 `Data:Tc4research.json`（修订 671946，2026-06-29）。这些页面只用于核验 `Parents`、`ParentsHidden` 等字段语义；实际队列始终以当前整合包运行时注册的 `ResearchItem` 为准。目标测试版本为 `GTNH-daily-2026-07-13+622`。

## 加权求解版本

本分支将求解器迁移到模组内部，不再启动 Windows 专用的外部 DLL，并新增：

- 普通最短与加权最短模式；
- 研究桌内的要素权重编辑、禁用、Wiki 默认和按当前库存分配权重；
- 原生要素图标、中文名/标签搜索、按名称/权重/库存排序，以及禁用/缺货筛选；
- 悬停查看组成要素、当前库存、权重和启用状态；
- 命名权重方案，并通过剪贴板导入或导出 JSON；
- 库存感知、确定性结果、搜索超时与普通模式自动回退；
- 执行前预览总权重、落子数、预计合成次数、求解耗时、展开状态、缓存和估算工作内存；
- 关闭界面、切换笔记或修改权重后自动丢弃过期结果。
- 单线程研究任务队列、相容图缓存、容量为 8 的结果缓存和仅脏配置写盘。
- 相同物理盘型复用容量为 32 的棋盘几何缓存；相容图命中时不再重复排序和拼接全部要素定义，图重建会使旧结果缓存失效。
- 整数索引 Dijkstra、复用搜索数组与堆，并预编译权重、禁用状态、邻接表和相容表，避免搜索内层的对象分配与字符串查询；
- 自动解锁改为客户端 Tick 状态机：后台只求解快照，合成和落子均在客户端主线程发送，并等待服务端状态确认；
- 研究台右侧提供“批量研究并解锁”，先学习已完成的发现，再依次扫描玩家主物品栏和快捷栏中的有效未完成笔记，逐张装入、求解、确认并移回物品栏；
- 笔记题面使用稳定指纹识别，可跨越 Thaumcraft 每帧重建的笔记数据对象，并支持已有玩家落子的半完成笔记；
- 合成逐项确认；落子在一个 Tick 内批量发送，超时后只重发未确认格，最多 3 轮。只有服务端确认笔记完成后才显示成功。
- 路线回溯禁止重复使用同一物理格；候选生成后和批量落子前都会执行整盘六向连通性预检，失败方案不会消耗要素或笔墨；
- 固定锚点要素若尚未发现，会先合成一次以满足 Thaumcraft 服务端完成判定。
- 仅对已证明无解的强制走廊尝试安全修复：先在笔记副本上删除候选冲突锚点、完整求解并验证整盘，验证成功后才向服务端修改；普通 `no_path` 不会删除锚点。
- 模组逻辑完全在客户端执行并使用 Thaumcraft 原版数据包，服务端不需要安装本模组；服务端若修改了研究协议或限制原版研究操作则不保证兼容。

在研究桌左侧点击“权重设置”进入配置界面。加权模式中，每条连接的代价为两端要素权重之和；权重越高，该要素越不容易进入结果。禁用仅影响自动生成的中间要素，不会删除笔记已有的固定要素。

“库存分配”按研究桌当前真实库存的中位秩百分位批量设置权重。百分位公式为 `p = (库存低于当前值的正库存要素数 + 同库存要素数 / 2) / 正库存要素总数`；正库存权重为 `2^floor(9 × (1 - p))`，缺货固定为最大档 `2^9 = 512`。所有权重均为 2 的幂，库存越多权重单调不增，相同库存必定得到相同权重；该操作不会清除已禁用要素。

设置保存在 `config/TCAutoResearch.cfg`，命名方案保存在
`config/TCAutoResearch-weight-profiles.json`。未知要素默认权重为 `16`，有效范围为 `0..512`。
